Universal Toolkit v1.0
======================

One launcher screen for a library of PowerShell and batch tools. Pick an
app, click Open, and it starts in its own window - elevated automatically
when the app needs admin rights.

Apps included
-------------
  Hardened Toolkit              Cleaner, duplicate finder, scanner, uninstaller.   ADMIN
  Component Optimizer           Optimizes, deduplicates and relocates components.  Standard
  Device Cleanup                Removes ghost and unused devices.                 ADMIN
  Executable Performance Mgr    Per-app priority, QoS, GPU and compatibility.     ADMIN
  DGs File Finder               Search ZIP archives and folders; extract.         Standard
  File and Folder Lister        Lists a directory to TXT or RTF.                  Standard
  Bulk Extension Renamer        Renames files from one extension to another.      Standard

Files in this folder
--------------------
  UniversalLauncher.ps1   Launcher source (hub UI, launch, install, uninstall).
  UniversalLauncher.exe   Compiled launcher (created by Build.bat).
  AppIcon.ico             Launcher icon (generated by Make-Icon.ps1).
  Make-Icon.ps1           Regenerates AppIcon.ico from code.
  Build.ps1               Build engine: icon -> EXE -> installer.
  Build.bat               One-click wrapper. Double-click this.
  Build-Installer.iss     Inno Setup 6 installer script.
  README.txt              This file.
  AppLibrary\             The apps themselves (unchanged originals).
  Output\                 Build output (installer lands here).

Using the launcher
------------------
  1. Double-click UniversalLauncher.exe (or right-click UniversalLauncher.ps1
     and choose Run with PowerShell).
  2. Click a card to select an app, then Open - or select it and press
     Launch selected.
  3. Apps that need admin show an "Admin" badge; approving the UAC prompt
     is all that is required.

Install and uninstall
---------------------
  Install shortcuts
      Copies the toolkit to %LOCALAPPDATA%\Programs\UniversalToolkit and
      creates the desktop and Start Menu shortcuts you tick. Each app also
      gets its own Start Menu shortcut. Safe to run again: it repairs the
      install.

  Uninstall
      Removes the shortcuts and the installed copy. The apps in AppLibrary
      and your own files are never modified.

  No admin rights are required for the launcher or the install itself.

One-time setup (only to rebuild)
--------------------------------
  1. Inno Setup 6               https://jrsoftware.org/isdl.php
  2. ps2exe                     Install-Module ps2exe -Scope CurrentUser

  Then double-click Build.bat. It regenerates the icon, compiles
  UniversalLauncher.exe, and builds Output\UniversalToolkit-Setup.exe.

Safety notes
------------
  - The launcher only starts the apps; it does not touch files itself.
  - Admin apps (Hardened Toolkit, Device Cleanup, Executable Performance
    Manager) make real system changes. Review each app's own warnings.
  - The launcher runs entirely locally. No network, no telemetry.

Adding more apps
----------------
  Drop a .ps1 or .bat into AppLibrary, then add one entry to the $Catalog
  list near the top of UniversalLauncher.ps1 and rebuild.

Troubleshooting
---------------
  "running scripts is disabled"
      Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

  "ps2exe not found" (building)
      Install-Module ps2exe -Scope CurrentUser

  UAC prompt keeps appearing
      Expected for Admin apps. Tick "Always" once per app if you trust it.

  SmartScreen on first run
      The EXEs are unsigned. Choose More info -> Run anyway.

  App missing from the list
      Make sure its file is present in AppLibrary\.
